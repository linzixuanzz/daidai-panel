# v4.0.1
<!-- release-title: v4.0 界面细节全面精修：对比度、浮层避让、主题适配与移动端布局 -->

集中修复 `v4.0.0` 界面焕新后全站 7 套主题、明暗双模式与多端视口下排查出的 55 项显示与交互问题。

## 重点修复

- **运行中浮窗不再遮挡分页器**：桌面端取消右下角冗余收起胶囊，展开浮窗改锚定在顶栏下方并改用不透明浮层底色，不再挡住底部分页按钮或透叠下层文字；移动端补充底部安全区与高度限制。
- **全站控件与日志对比度达标**：修复开关轨道与内联文字、按钮加载图标、全局 `v-loading` 遮罩、成功提示 Toast、徽章、`ThemeStudio` 不可用按钮以及浅色日志 ANSI 配色在 7 套主题 × 明暗 14 种组合下看不清或串色的问题，全部满足 WCAG AA 对比度；自定义日志背景图自动叠加保护遮罩。
- **主题工坊与主题特性修复**：修复非素白主题切换「自定义主色」不刷新主按钮的问题；修复「素白 / 晨雾」主题下表格、弹窗与分栏分隔线隐身、素白暗色卡片外框消失以及切换背景时侧栏毛玻璃意外失效的问题；明确设置「玻璃模糊 = 0」时正确关闭侧栏毛玻璃。
- **弹窗、安全模式与切页动效**：解除页面容器对弹窗的裁切；安全模式横幅改文档流占位，不再压住顶栏和主题工坊按钮；移动端关闭切页拉伸变形动画；修复快速连点切页或切主题时的过渡竞态。
- **移动端与窄屏布局**：修复 API 文档在 360–390px 手机端右侧裁切、脚本页移动端编辑器塌陷、配置/订阅/依赖页工具栏窄屏挤压、环境变量卡片标签碎裂、1024px 窄桌面任务表与概览卡挤压，以及系统设置多处表单和弹窗的小屏排版问题。

## 优化

- 清理 48 处 `<el-tag>` 空类型控制台警告与历史残留样式，前端运行期零警告。
- 修复直角模式下圆角漏适配、密度切换（紧凑 / 舒适 / 宽松）与「克制」动效档位局部未生效的问题。
- 代码编辑器（CodeMirror / Monaco）补齐 7 套主题色、搜索栏配色、Diff 字体字号与跨标签页同步；动态同步浏览器顶栏 `theme-color`。
- 优化仪表板 Bento 卡片排版与趋势图 Tooltip 防溢出、登录页暗色插画可见度、侧栏分组滑动指示条对齐，以及个人中心、通知渠道、Open API 与系统设置多处移动端加载态和文案细节。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
