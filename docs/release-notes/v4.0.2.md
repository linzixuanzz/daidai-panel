# v4.0.2
<!-- release-title: 大幅降低 v4 界面卡顿，新增流畅模式 -->

重点处理 v4.0 升级后的卡顿（#182）。

## 性能

- 大幅降低界面渲染开销：在没有显卡加速的设备上（老电脑、远程桌面、浏览器关了硬件加速），空闲、切页、滚动的帧率从十几帧恢复到接近 v3.4.5。
- 新增「流畅模式」：关掉毛玻璃、背景光斑与装饰动画；检测到设备渲染较慢时自动开启，可在「个人设置 → 界面外观」或 `Ctrl K` 切换。
- 动效「跟随系统」默认改为「克制」；背景漂移、切页动画、指针光斑只在手动选「丰富」时开启。
- 卡片默认改为实色，不再透底模糊；想要毛玻璃卡片可在主题工坊调高「玻璃模糊」。
- 仪表板「未来 24 小时」、执行统计等接口提速，任务和日志多时不再拖慢面板。

## 修复

- 修复 Debian 镜像换源时误改 nginx 官方源，导致所有 Linux 依赖安装失败（#184、#185），升级后自动修回。
- 脚本管理跳过 `.npm-cache` 等缓存目录，文件特别多的目录改为点开时再加载，不再加载超时（#183）。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
