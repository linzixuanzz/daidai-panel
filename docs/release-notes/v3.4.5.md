# v3.4.5
<!-- release-title: 安全更新：修复 Docker 镜像内置 nginx 的 NGINX2Root 高危漏洞 -->

## 安全

- Docker 镜像内置 nginx 升级到已修复 NGINX2Root（CVE-2026-123007 / 123633 / 121810 / 123634 / 113425）的版本：Alpine 镜像为 1.28.3-r8，Debian 镜像改用 nginx.org 官方源 1.30.7。
- 面板默认的 nginx 配置没有开 HTTP/2、HTTP/3、resolver 和 mail，不满足这些漏洞的触发条件，但仍建议尽快更新。Windows、Linux 二进制和 Magisk 版不含 nginx，不受影响。

## 注意

- Alpine 镜像里 `nginx -v` 修复前后都显示 1.28.3，确认是否已修复请执行 `docker exec <容器名> apk list -I nginx`，看到 `-r8` 即可。
- 这个漏洞链里的提权漏洞还没有内核补丁，容器内修不了，建议在宿主机用 root 执行 `echo 'install sctp /bin/false' > /etc/modprobe.d/disable-sctp.conf` 禁用 SCTP 内核模块。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 版本次无功能变化，可按需更新。
