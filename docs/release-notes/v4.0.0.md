# v4.0.0
<!-- release-title: 界面焕新：7 套主题、主题工坊、命令面板、仪表板重做 -->

## 新外观

- 7 套风格可选：经典、极光（默认）、晨雾、终端、纸墨、呆呆、素白，每套都有明暗两版；明暗按钮的用法不变。
- 新增「主题工坊」（侧栏或顶栏打开）：风格、主色、背景、玻璃模糊、圆角、密度、动效强度都能调，可导出 / 导入。管理员还能「设为全站默认」和写自定义 CSS。
- 动效分「跟随系统 / 丰富 / 克制 / 关闭」四档，低配设备自动降为「克制」。
- 侧栏按「运行 / 资源 / 其他 / 管理后台」分组，切页、切主题都有过渡动画。

## 新功能

- 仪表板重做：健康分、需要关注（连续失败的任务、拉取失败的订阅、安装失败的依赖、磁盘占用过高，可一键重跑）、未来 24 小时调度、实时执行流、任务健康画像。卡片可拖动排序和隐藏，支持大屏模式。
- `Ctrl K` 命令面板：跳页面、搜任务 / 脚本 / 变量 / 订阅、直接运行任务，支持拼音首字母。另有 `g` + 字母跳页，`?` 查看全部快捷键。
- 定时任务：展开行查看健康画像（近 13 周热力格、耗时趋势、P90），新增「最近 20 次」小柱图，运行中的任务有流光标识。
- 运行中浮窗：任意页面都能看正在运行的任务和日志尾部，可直接停止。
- 网页可以安装成应用；开启「桌面通知」后，任务新出现连续失败会弹系统通知（面板开着时生效）。
- 手机上定时任务卡片的「···」菜单新增「打开脚本」，一步打开任务对应的脚本（#180）。

## 注意

- 升级后「界面圆角」会一次性改成「跟随主题」，之后再改成直角或圆角会一直保持。
- 自定义 CSS 把页面弄乱时，在地址后加 `?safe=1` 进入安全模式，再到主题工坊里修改。
- 桌面通知只在面板网页开着时有效，网页关掉后的提醒请用通知渠道。
- APP 不受影响，新增的外观设置只对网页生效，也不会出现在 APP 的系统设置里。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
