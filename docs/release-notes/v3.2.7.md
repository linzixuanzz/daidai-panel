# v3.2.7
<!-- release-title: 删除任务可一并删除脚本；企业微信应用支持代理；订阅拉取不再改动已有任务 -->

## 新功能

- 删除任务时可选同时删除脚本文件（#124）：默认不勾，单删、批量都支持；被共用、属于订阅、正在运行的脚本会自动保留。
- 企业微信应用通知新增「代理地址」（#123）：支持 http / https / socks5，留空使用系统代理。
- 置顶任务改为整行高亮，名称不再错位（#125）。

## 修复

- 改过参数的订阅任务再次拉取时不再重复新建（#125）。
- 企业微信应用、Telegram 的报错不再显示带密钥的请求地址。

## 注意

- 订阅拉取不再修改已有任务的名称和定时，「已锁定」随之取消；想恢复订阅默认，删掉任务重新拉取。订阅里已经没有对应脚本的任务，按「自动删除失效任务」开关处理（#125）。
- 保存通知渠道时会校验代理地址格式（只校验新填写或改动过的值）。
- 接口变化：新增 `POST /api/v1/tasks/delete-preview`；移除 `PUT /api/v1/tasks/:id/restore-subscription-default` 和任务的 `subscription_locked` 字段；Open API 应用令牌在删除任务时一并删除脚本，需要 scripts 权限。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
