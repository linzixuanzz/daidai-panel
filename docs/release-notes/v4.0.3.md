# v4.0.3
<!-- release-title: 铃铛支持一键已读，脚本管理打开更快 -->

## 新增

- 顶栏铃铛与仪表板「需要关注」支持「全部已读」，点「查看」「日志」后该条也算已读；同一问题再次发生时会重新提醒（#186）。

## 优化

- 脚本管理打开更快：读取文件信息的开销减半，文件多时更早改为点开再加载（#183）。
- `conc` / `desi` 运行时，日志开头会说明本次跑的是第几个账号；每个进程只拿到自己的账号，脚本里显示的「账号1」以行首 `[变量名#序号]` 为准（#187）。
- 开放 API 超出速率限制时，报错会写明每小时上限和修改位置。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
