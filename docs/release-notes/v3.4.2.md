# v3.4.2
<!-- release-title: 支持通行密钥登录，修复一批安全问题，飞书通知可选富文本和卡片 -->

## 新功能

- 支持通行密钥（Passkey）：在「设置 → 账号安全 → 通行密钥」添加后，登录页点「使用通行密钥登录」，用指纹、面容或设备 PIN 直接登录；两步验证那一步也可以「改用通行密钥验证」（#175）。
- 飞书通知新增「消息类型」：文本、富文本、卡片。富文本标题加粗，卡片标题显示在彩色标题栏里（#172）。
- 环境变量页新增「刷新」按钮，按当前筛选重新拉取（#174）。
- 新增审计日志：改密码、用户管理、备份恢复、命令行执行、系统配置修改等敏感操作都会留下记录，管理员在「设置 → 账号安全 → 审计日志」查看。

## 安全

- 构建工具链从 Go 1.25 升级到 Go 1.27.3，并升级 golang.org/x/net 等依赖，修复标准库与依赖中的一批已知漏洞（含 crypto/x509 的 GO-2026-6809）。
- 订阅的保存目录和别名不能再指向脚本目录以外。
- 不再采信 `CF-Connecting-IP`、`True-Client-IP` 请求头，伪造来源 IP 绕不过登录限流与锁定。
- 开放 API 的「系统备份」权限只能创建、列出、下载备份；上传、恢复、删除改为必须用管理员账号。
- 上传备份会先校验内容，同名文件自动改名，不再覆盖。
- 在线更新会用 GitHub 公布的 SHA-256 校验更新包，校验不过不更新。
- 加密备份改用加盐的 PBKDF2 派生密钥；Android 运行时安装包里指向安装目录以外的符号链接会被跳过。
- 开放 API 取令牌按失败次数限流；续期、初始化等公开接口加了限流和请求体大小上限。
- 其他：CORS 不再放行 `Origin: null`，CSP 去掉 `unsafe-eval`，邮件头过滤换行，git、pip、npm 防参数注入，调试运行 ID 改为随机，登录日志保留 90 天。

## 注意

- 新设或修改的密码需 8 位以上，且字母、数字、符号至少包含两种；已有密码照常登录。
- 面板前面套了 Cloudflare CDN 的，请把 Cloudflare 的 IP 段填进「设置 → 代理设置 → 可信代理 CIDR」，否则登录限流会按 Cloudflare 节点 IP 计算。同时开了 IP 白名单的，升级后可能进不了面板：先在容器或终端执行 `ddp ip-whitelist clear`，填好可信代理 CIDR 后再把白名单加回来。
- 本版本生成的加密备份，旧版本面板无法恢复。
- 已有订阅如果保存目录指向脚本目录以外（包括软链到外部的目录），拉取会失败并提示修改。
- 任务超时最长 7 天、失败重试最多 10 次、重试间隔最长 1 小时。

- 通行密钥只能在 HTTPS 域名（或 localhost）下使用，用 `http://IP:端口` 访问时按钮不可用。每个通行密钥绑定添加时的访问地址，换地址或端口访问需要重新添加。
- 添加通行密钥要输入当前密码，开了两步验证的还要输入验证码；修改或重置密码会一并清除该账号的通行密钥。
- APP 暂不支持通行密钥，照常用密码和两步验证码登录。
- 已有的飞书渠道默认仍是文本，行为不变。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
