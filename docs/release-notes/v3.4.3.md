# v3.4.3
<!-- release-title: 新增后台进程页，检查更新遇到 GitHub 限流不再每天报错，修复编辑器查找跳转 -->

## 新功能

- 新增「后台进程」页（侧栏「定时任务」下方，管理员可见）：查看任务里用 `setsid nohup … &` 拉起、仍在运行的进程，显示所属任务、命令、运行时长和内存，可直接结束；打开「显示全部进程」可查看容器里的其它进程（#176）。
- 「设置 → 代理设置」新增 GitHub Token，用于提高检查更新的访问额度（#177）。

## 修复

- 检查更新遇到 GitHub API 限流时，提示状态码和大约几点恢复；静默更新不再因限流每天发失败通知，额度恢复后自动重查；手动检查更新在限流时也能显示最新版本号（#177）。
- 修复开启「减少动态效果」时，编辑器查找点「上一个 / 下一个」不跳到对应行（#178）。
- 订阅拉库在内核低于 3.17 的宿主机上失败时，日志说明原因和解决办法（#173）。

## 注意

- 任务运行时会带上环境变量 `DAIDAI_TASK_ID`（当前任务 ID）。
- GitHub API 被限流期间，二进制部署与 Magisk 模块要等额度恢复后才能一键更新。
