# v3.4.4
<!-- release-title: 修复一批安全问题，Qmsg 通知适配 3.0 接口、群发恢复正常 -->

## 修复

- Qmsg 通知改用 Qmsg 3.0 接口，「群发」模式会发到填写的 QQ 群，不再走私聊（#179）。

## 安全

- 可信代理默认只信任本机，私网来源伪造 `X-Forwarded-For` 不再能绕过 IP 白名单、登录限流和锁定。
- 登录用户名先去掉首尾空格再判断锁定，加空格绕不过账号锁定。
- 两步验证码用过一次即失效，不能在有效期内重复登录；两步验证已开启时，需先关闭才能重新绑定。
- 用户名不存在与密码错误的登录耗时一致；账号被禁用时，密码正确才会提示「账号已禁用」。
- 企业微信触发链接在任务被禁用、签发它的应用被禁用或删除后立即失效，并限制触发频率。
- 企业微信回调拒绝超过 5 分钟的旧消息，同一条消息重复投递只执行一次。
- 头像上传校验 WebP 文件内容。
- 升级 axios、vue、echarts、dompurify 等前端依赖，修复其中的已知漏洞。

## 注意

- 面板在宿主机 nginx、宝塔、Lucky 等反代后面的，请在「设置 → 代理设置 → 可信代理 CIDR」填上反代访问面板的来源地址（Docker 默认一般是 `172.17.0.1`，不确定可填 `172.16.0.0/12`），否则登录日志与限流看到的都是反代地址。之前手动改过这一项的不受影响。
- 同时开了 IP 白名单的，升级后可能进不了面板：先在容器或终端执行 `ddp ip-whitelist clear`，填好可信代理后再把白名单加回来。
- Qmsg 群发需要先在 Qmsg 控制台添加并绑定该群；群发模式必须填写群号。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
